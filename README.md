# Number Guessing Game 🎮

A simple Number Guessing Game built with Python.

## Features

- Random number generation
- User input handling
- Unlimited guessing attempts
- Too High / Too Low hints
- Attempt counter
- Winning message

## Concepts Used

- Python Basics
- While Loop
- If-Elif-Else
- User Input
- Random Module
- Loop Control (break)

## How It Works

1. The computer generates a random number between 1 and 100.
2. The user tries to guess the number.
3. The program provides hints:
   - Too High
   - Too Low
4. The game continues until the correct number is guessed.
5. The total number of attempts is displayed.

## Example

Guess the number: 50
Too Low

Guess the number: 80
Too High

Guess the number: 67
Congratulations!
